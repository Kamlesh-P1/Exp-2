# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:
To develop the Library Management System using Star UML


# SRS (Procedure):
# STEP 1

Library Management System is required to replace the manual tracking of books, member records, and lending activities, which is prone to errors and inefficiency.

# STEP 2

Manual processes cause difficulties in managing book availability, overdue returns, and accurate record-keeping of issued and returned books.
# STEP 3

Library users face challenges in searching for books, checking availability, and reserving or renewing books without visiting the library physically.
# STEP 4

Librarians need an automated system to catalog books, manage memberships, track loans, and send notifications for due dates and fines.

# STEP 5

The system should support quick check-in/check-out, fine calculation, and generate reports on inventory, borrowing trends, and user activity.

# STEP 6

It must provide secure role-based access for users and librarians, ensuring data integrity and protecting sensitive user information. UML DIAGRAMS
